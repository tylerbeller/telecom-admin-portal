# Data and privacy policy

This portal is a demo system. This policy exists so that stays true as the
codebase changes hands.

## What data lives here

None that is real. The database is generated by `scripts/seed-database.py`
from fake names, addresses, and usage patterns. The schema can never receive
production data because the application is never deployed anywhere production
traffic can reach it.

## The rules

1. **No real customer data, ever.** Not in the database, not in fixtures, not
   in tests, not in screenshots attached to issues or PRs.
2. **No public exposure.** The application binds to localhost in every
   supported run mode. Do not put it behind a tunnel or a public host.
3. **Retention is trivial by design.** `pnpm reset:db` destroys and
   regenerates the entire dataset. That is the retention mechanism and the
   deletion mechanism; there is nothing else to expire.
4. **Logs carry no payloads.** The backend logback pattern masks long digit
   runs and email-shaped strings, and the frontend logger redacts known PII
   field names. If you add a log statement, keep payloads out of it.

## If real data ever appears here

Treat it as an incident: stop, purge the file or row, rotate anything it
touched, and open an issue describing how it got in.
